# Regra: Sempre enviar para o GitHub

- Ao concluir qualquer implementação, correção ou melhoria solicitada pelo usuário no projeto Primacor Kaban, sempre realizar o commit das alterações e efetuar o push para o GitHub (`git push origin main`).
- Manter o repositório remoto sempre atualizado com as últimas versões do código.
